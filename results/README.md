# Financial results require validated inputs

This public revision publishes corrected research code and synthetic calculation checks. It does not publish outputs, fingerprints or metadata from private Drive inputs. Original public results are superseded and retained only under ../archive/.

The root notebook reports diagnostics locally when the user supplies source files. Default legacy mode cannot certify historical identities and withholds full-period performance. The dated-link mode also requires review of source coverage and missing/terminal payoffs. Computation alone does not establish investment viability or out-of-sample prediction.

See ../docs/RESULTS.md for output definitions and exact-code synthetic examples. Private source files and their local output directories must not be committed.
